# Local AI Research Notes

## Local-First Design

A local research assistant should optimize for privacy, reproducibility, and transparent citations. Documents should stay on the user's machine unless the user explicitly chooses an external provider.

## Retrieval Quality

Useful research retrieval depends on chunk quality, query matching, ranking, and citation display. A good assistant should show where each answer came from.

## Memory

Research memory should store durable project preferences, decisions, and recurring context. It should not silently treat every conversation as permanent memory.
